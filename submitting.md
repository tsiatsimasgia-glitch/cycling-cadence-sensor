# Project Submission: Smart Dual-Band Cycling Cadence Sensor

## Overview
This project is an open-source, dual-protocol (ANT+ and BLE) cycling cadence sensor designed for triathlon training, built around the Seeed Studio XIAO nRF52840 microcontroller.

## Documentation & Implementation Checklist
- **Firmware:** Located in `/firmware/cadence_sensor.ino` with low-power sleep management.
- **Bill of Materials:** Tracked via `BOM.csv`.
- **Hardware Circuit:** Simulated and mapped via `/hardware/circuit.json`.
- **Development Environment:** ChromeOS-compatible toolchain using Wokwi and Arduino Cloud Web IDE.
