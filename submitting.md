# Project Submission: Smart Dual-Band Cycling Cadence Sensor

## Overview
This project is an open-source, dual-protocol (ANT+ and BLE) cycling cadence sensor designed for triathlon training, built around the Seeed Studio XIAO nRF52840 microcontroller and a KY-003 Hall Effect sensor.

## Documentation & Implementation Checklist
- **Firmware:** Located in `/firmware/cadence_sensor.ino` with low-power sleep management.
- **Bill of Materials:** Tracked via `BOM.csv`.
- **Hardware Circuit:** Simulated and mapped via `/hardware/circuit.json`.
- **3D CAD Assembly & Enclosure:** Custom 3D-printable crank enclosure and mount STL file stored in the root directory / cad folder for secure bike mounting.
- **Development Environment:** Wokwi simulation and Arduino Cloud Web IDE toolchain.
